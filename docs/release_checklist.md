# Release

1. Build the world and Windows host bundle. Install the packaged world in Archipelago 0.6.8 and generate a two-player seed with the group's settings.
2. Build both patches using the packaged host helper. Apply them with OoTMM Patch mode. Connect both players and verify item exchange and save/reconnect. Play through the configured goal when changing completion behavior.
3. Package the playtest with build receipts and verify the bundle. Publish the world, player and host bundles and their checksums. Keep ROMs, spoilers and server data private.

Use the [host and player setup guide](setup_en.md) to run the installation and the [playtest checklist](playtest_en.md) to check gameplay affected by the release.
